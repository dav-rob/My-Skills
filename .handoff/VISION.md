# Vision

Distribute all skills from any GitHub repository to every tool that can use them,
as safely and securely as possible.

Safety and security are the primary design goals throughout discovery, auditing,
installation, updates and removal. Treat externally supplied skills as untrusted
and prevent distribution from granting unintended access or causing harm.

Success means people can deliberately choose skills from any source repository
and make them available across their compatible tools with clear evidence about
what was checked, what was installed and what risks or uncertainties remain.

`dav-rob/My-Skills` is one source repository. The current tool list, static audit
and GitHub CLI wrapper are today's implementation, not limits on the vision.
